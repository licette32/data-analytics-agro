## 🧭 Cómo está armado cada caso

Cada carpeta dentro de `casos/` tiene su propio README con:

- **Contexto** — el problema o pregunta agro que motiva el análisis
- **Datos** — origen y descripción del dataset
- **Enfoque** — metodología y herramientas utilizadas
- **Hallazgos** — resultados principales, con los gráficos o el dashboard que los respaldan
- **Qué haría distinto** — con más tiempo o más datos disponibles

<details>
<summary>📁 Ver estructura completa del repositorio</summary>

```text
casos/            Casos de análisis — cada uno con su propio problema, datos y hallazgos
proyecto-final/   Trabajo final integrador de la diplomatura (independiente de los casos)
docs/             Metodología general y consignas originales, como referencia
datasets/         Datos crudos utilizados (cuando el tamaño lo permite versionarlos)
```
